# Prompt Tuning Scorecard

Use this scorecard for Day 6 prompt tuning.

## Goal

Evaluate 10 real inputs per prompt and rewrite any prompt that scores below 7/10.

## Prompts To Review

1. `/describe`
2. `/recommend`
3. `/generate-report`

## Scoring Rubric

Score each response from 1 to 10 for:

1. Accuracy
2. Completeness
3. Format compliance
4. Clarity
5. Safety

## Rewrite Rule

If the average score for a prompt is below 7/10, revise the prompt and retest with 10 fresh inputs.
